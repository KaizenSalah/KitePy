## Requirements

Declared in `pyproject.toml`:

- **Python**: `>= 3.8` (CI tests Python `3.10`, `3.11`, `3.12`)
- **Core dependencies**:
  - `torch >= 2.0.0`
  - `torchvision >= 0.15.0`
  - `timm >= 0.9.0`
  - `pyyaml >= 6.0`
  - `numpy >= 1.21.0`

---

## Installation Methods

### Standard Install (PyPI)

```bash
pip install kitepy
```

### Optional Dependency Extras

Choose the optional extras matching your workflow (defined in `pyproject.toml`):

| Extra | Command | Included Packages |
|-------|---------|-------------------|
| **Language / HF** | `pip install "kitepy[llm]"` | `transformers>=4.30.0`, `datasets>=2.12.0`, `tokenizers>=0.13.0` |
| **Distributed** | `pip install "kitepy[distributed]"` | `deepspeed>=0.9.0`, `accelerate>=0.20.0` |
| **Experiment Tracking** | `pip install "kitepy[tracking]"` | `wandb>=0.15.0`, `tensorboard>=2.13.0` |
| **Advanced GPU** | `pip install "kitepy[advanced]"` | `flash-attn>=2.0.0`, `bitsandbytes>=0.41.0` |
| **Development** | `pip install "kitepy[dev]"` | `pytest>=7.3.0`, `pytest-cov>=4.1.0`, `black>=23.3.0`, `flake8>=6.0.0`, `mypy>=1.3.0`, `isort>=5.12.0` |
| **All Extras** | `pip install "kitepy[all]"` | Combines `llm`, `distributed`, and `tracking` packages |

### Additional Lazy Optional Packages

Certain features import optional libraries at call time when invoked:

- **SafeTensors bundles** (`safe=True`, `format="safetensors"`): `pip install safetensors`
- **Tabular CSV loading**: `pip install pandas`
- **LoRA fine-tuning via HuggingFace PEFT** (`lora=True` falls back to built-in `LoRALinear` if absent): `pip install peft`
- **FastAPI serving** (`.to_fastapi()`, `kitepy serve`): `pip install fastapi uvicorn`
- **Optuna hyperparameter search** (`.tune()`): `pip install optuna`
- **HuggingFace Hub upload** (`.push_to_hub()`): `pip install huggingface_hub`
- **Non-WAV audio formats** (`.flac`, `.ogg`, `.mp3`): `pip install torchaudio` (built-in Python `wave` handles `.wav` with zero extra deps)
- **Diffusion UNet preset** (`Generative("diffusers_unet")`): `pip install diffusers`
- **ONNX export / plotting / Lion optimizer**: `onnx`, `matplotlib`, `lion-pytorch`

### Install From Source

```bash
git clone https://github.com/KaizenSalah/kitepy.git
cd kitepy
pip install -e ".[dev]"
```

### PyTorch With CUDA

Install the CUDA build of PyTorch matching your driver before or alongside `kitepy`:

```bash
pip install kitepy torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

## Verify Installation

From the CLI:

```bash
kitepy doctor
```

Or in Python:

```python
import kitepy
from kitepy import CNN, print_device_info, print_version_info

print("KitePy version:", kitepy.__version__)
print_version_info()
print_device_info()

# Zero-download 1-batch sanity check
CNN("resnet18").train("synthetic", epochs=1, fast_dev_run=True, save_every_n_epochs=0)
```
