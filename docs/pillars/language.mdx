## Overview

The Language pillar exposes two public APIs built on `BaseModel` and `LLMConfig`:
- **`LLM`**: Causal language modeling (`"causal_lm"`, default) or sequence classification (`"classification"`).
- **`TextClassifier`**: Convenience subclass defaulting to `task="classification"` and `num_labels=num_classes`.

## Simple vs. Advanced Usage

<CodeGroup>
```python TinyGPT Quickstart (Offline)
from kitepy import LLM

llm = LLM("tiny_gpt", context_length=128)
llm.train(["kitepy simplifies deep learning", "pytorch models in one line"], epochs=5, batch_size=2)
print(llm.generate("kitepy", max_new_tokens=20, temperature=0.7))
```

```python HuggingFace + PEFT LoRA
from kitepy import LLM

llm = LLM(
    "Qwen/Qwen2.5-0.5B",
    pretrained=True,
    lora=True,
    lora_r=8,
    lora_alpha=16,
    lora_dropout=0.05,
    context_length=512,
)
llm.train(
    "my_chat.jsonl",
    epochs=3,
    batch_size=8,
    lr=2e-4,
    auto_plan=True,
)
print(llm.generate("<|user|>\nExplain KitePy.\n<|assistant|>\n", max_new_tokens=64, temperature=0.0))
```

```python Text Classification
from kitepy import TextClassifier

clf = TextClassifier("tiny_gpt", num_classes=2, context_length=128)
clf.class_names = ["neg", "pos"]

clf.train(
    [
        {"text": "clean api and fast training", "label": 1},
        {"text": "broken build and confusing errors", "label": 0},
    ] * 10,
    epochs=5,
    batch_size=4,
)
print(clf.predict("clean api", top_k=2))
```

```python Streaming Huge JSONL
from kitepy import LLM

# Constant-memory IterableDataset over large .jsonl / .txt files
llm = LLM("gpt2", pretrained=True, lora=True, context_length=512)
llm.train(
    "huge_corpus.jsonl",
    streaming=True,
    max_steps=500,
    batch_size=4,
    max_length=512,
)
```

## Backends, Tokenizers, & LoRA

### Model Resolution (`_is_hf_model`)

`LLM` routes to HuggingFace `AutoModelForCausalLM` / `AutoModelForSequenceClassification` whenever:
- `custom_model is None`, AND `model_name != "tiny_gpt"`, AND (`pretrained=True`, or `"/" in model_name`, or `Path(model_name).is_dir()`).

Otherwise, `"tiny_gpt"` uses the built-in pure-PyTorch `TinyGPT` paired with a byte-level `SimpleCharTokenizer` (`vocab_size=260`: `0=PAD`, `1=BOS`, `2=EOS`, `3..258=UTF-8 bytes`). If a HuggingFace tokenizer lacks `pad_token_id`, KitePy assigns `pad_token = eos_token`.

### LoRA Injection (`lora=True`) & PEFT Persistence

When `lora=True`, `LLM._build_model()`:
1. Uses HuggingFace `peft` (`LoraConfig` + `get_peft_model`) if installed.
2. Otherwise falls back seamlessly to KitePy's built-in `apply_builtin_lora()`, which freezes all base weights and wraps matching projection linear layers (`q_proj`, `k_proj`, `v_proj`, `o_proj`, `out_proj`, `c_attn`, `c_proj`, `gate_proj`, `up_proj`, `down_proj`, `proj`, `qkv`) in `LoRALinear`.

When saving a PEFT-wrapped model (`llm.save("run.pt")` or `safe=True`), `LLM` automatically exports companion adapter weights and tokenizer files into `<stem>.peft_adapter/` via `save_pretrained()` and records `peft_adapter` metadata. Calling `LLM.load("run.pt")` reloads the base model and attaches the saved adapter via `PeftModel.from_pretrained()` cleanly (while built-in `TinyGPT` + LoRA bundles reload directly from `.pt` or `.safetensors`).

## Supported JSON / JSONL / List Formats

`format_chat_record()` automatically recognizes:
- **ChatML / Messages**: `{"messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]}` (uses HuggingFace `tokenizer.apply_chat_template` when present, or `<|role|>\ncontent` formatting).
- **Alpaca / Instruction**: `{"instruction": "...", "input": "...", "output": "..."}` (also accepts `"response"`).
- **Prompt / Completion**: `{"prompt": "...", "completion": "..."}` (or `"response"`).
- **QA**: `{"question": "...", "answer": "..."}`.
- **Plain Text**: `{"text": "..."}`, `{"content": "..."}`, `.txt` lines, or raw Python strings.
- **Classification Labels**: Add `"label": int` inside records for `TextClassifier` / `LLM(..., task="classification")`.
- **HuggingFace Datasets**: `"wikitext"` (`wikitext-2-raw-v1`) or `"hf://<repo>"` (requires `datasets`).

Dynamic batch padding via `make_language_collate_fn()` pads each batch only to the longest sequence in that batch and sets masked padding labels to `-100`.

## Text Generation (`LLM.generate()`)

```python
text = llm.generate(prompt="Once upon a time", max_new_tokens=32, temperature=0.7)
```

- `temperature <= 0`: deterministic greedy decoding (`do_sample=False` for HF models; `.argmax()` for `TinyGPT`).
- `temperature > 0`: multinomial temperature sampling.
