## Overview

`Tabular` provides neural baselines (`TabularResNet` and `TabularMLP`) for both **classification** and **regression** across `.csv` files, `(X, y)` NumPy/Tensor tuples, and `"synthetic"` datasets.

```python
from kitepy import Tabular

Tabular("tabular_resnet", task="classification").train("iris.csv", epochs=20)
```

---

## Simple vs. Advanced Usage

<CodeGroup>
```python CSV Classification & Regression
from kitepy import Tabular

# Last CSV column is used as target automatically
clf = Tabular("tabular_resnet", task="classification")
clf.train("iris.csv", epochs=15)

reg = Tabular("tabular_mlp", task="regression")
reg.train("housing.csv", epochs=15)
```

```python NumPy / Tensor Tuple Input
import numpy as np
from kitepy import Tabular

X = np.random.randn(200, 12).astype(np.float32)
y = (X[:, 0] * 1.5 - X[:, 1]).astype(np.float32)

model = Tabular("tabular_resnet", task="regression", input_dim=12, hidden_dims=[256, 128, 64])
model.train((X, y), epochs=10, batch_size=32)

# Continuous regression predictions
preds = model.predict(X[:4], top_k=1)
```

```python Custom Tabular Module
import torch.nn as nn
from kitepy import Tabular

custom_net = nn.Sequential(nn.Linear(12, 32), nn.ReLU(), nn.Linear(32, 3))
model = Tabular(custom_net, input_dim=12, num_classes=3)
prof = model.profile()  # Automatically uses shape (1, input_dim) before first train/predict
```

## Presets (`TABULAR_PRESETS`)

| Preset | Class | Default `hidden_dims` | Task Options |
|---|---|---|---|
| `"tabular_resnet"` | `TabularResNet` | `[128, 128, 64]` | `"classification"`, `"regression"` |
| `"tabular_mlp"` | `TabularMLP` | `[128, 64]` | `"classification"`, `"regression"` |

When `task="regression"`, `Tabular` automatically defaults to `loss="mse"`, `RegressionAdapter` (tracking `mae` and `rmse`), `out_dim=1`, and continuous `.predict()` / `.to_fastapi()` outputs.

## How CSV Preprocessing Works

When passing a `.csv` path to `.train()` (`pandas` required), `fit_tabular_preprocessor()` fits and persists the preprocessing schema (`model.preprocessor`):
1. Treats the **last column** (`df.columns[-1]`) as the target and drops rows where the target is `NaN`.
2. Imputes missing numeric features using stored column medians (`fillna(median)`) and categorical missing entries as `"missing"`.
3. Applies `pd.get_dummies(..., drop_first=False)` and stores the exact `dummy_columns` order.
4. Standardizes features (`(vals - mean) / std`, clamping zero-variance columns to `std=1.0`) and stores `mean`/`std`.
5. For `"classification"`, encodes categorical string/integer labels automatically and sets `num_classes` and `class_names`.

`model.preprocessor` is saved inside `.save()` checkpoints (including `.meta.json` for `safe=True`) and restored automatically by `Tabular.load()`, so reloaded models accept raw `dict`, `list[dict]`, `pandas.DataFrame`, `.csv` paths, or raw numeric rows in `.predict()` and `.to_fastapi()`.
