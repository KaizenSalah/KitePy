## Directory Layout

Place ImageNet under `<data_dir>/imagenet/{train,val}`:

```text
data/
└── imagenet/
    ├── train/ ...
    └── val/   ...
```

## Multi-GPU Training Configuration

```python
from kitepy import CNN, EarlyStopping, ModelCheckpoint, CSVLogger

model = CNN("resnet50", pretrained=False)
model.train(
    "imagenet",
    data_dir="./data",
    epochs=90,
    batch_size=64,
    gradient_accumulation_steps=4,
    lr=0.1,
    optimizer="sgd",
    optimizer_kwargs={"momentum": 0.9},
    weight_decay=1e-4,
    scheduler="cosine",
    warmup_steps=0.05,
    augmentation="randaugment",
    label_smoothing=0.1,
    ema=True,
    use_accelerate=True,
    checkpoint_dir="./checkpoints/imagenet",
    callbacks=[
        EarlyStopping(monitor="val_loss", patience=10),
        ModelCheckpoint(filepath="./checkpoints/imagenet/best.pt", save_best_only=True),
        CSVLogger(log_dir="./logs/imagenet"),
    ],
)
```

Launch across GPUs with Accelerate:

```bash
accelerate launch --multi_gpu train_imagenet.py
```
