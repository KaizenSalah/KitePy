## LR Finder + Differential LR + Safe Export

```python
from kitepy import Transformer

# 1. Load pretrained Swin-Tiny
model = Transformer("swin_tiny", pretrained=True, num_classes=10)

# 2. Freeze backbone for head adaptation
model.freeze_backbone()
model.train("cifar10", epochs=2, batch_size=64, lr=1e-3)

# 3. Unfreeze last 2 stages & find an empirical LR
model.unfreeze(layers=2)
suggested_lr = model.find_lr("cifar10", batch_size=64)
print(f"Suggested LR: {suggested_lr:.2e}")

# 4. Fine-tune with differential LR + EMA + SafeTensors save
model.train(
    "cifar10",
    epochs=5,
    batch_size=64,
    lr={"backbone": suggested_lr * 0.1, "head": suggested_lr},
    ema=True,
    safe_serialization=True,
)

model.save("./artifacts/swin_cifar10.safetensors", safe=True)
model.export("./artifacts/swin_cifar10.onnx", format="onnx", input_shape=(1, 3, 224, 224))
```

Serve directly from the terminal:

```bash
kitepy serve ./artifacts/swin_cifar10.safetensors --modality vision --port 8000
```
