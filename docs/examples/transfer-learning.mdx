## Balanced Custom ImageFolder Transfer Learning

```python
from kitepy import CNN, EarlyStopping, CSVLogger

# Automatically detects classes from ./my_images/{class_a,class_b,...}
# and computes inverse-frequency class weights when classes are imbalanced
model = CNN("convnext_tiny", pretrained=True)
model.freeze_backbone()

model.train(
    "./my_images",
    epochs=5,
    batch_size=32,
    lr=1e-3,
    class_weights="balanced",
    augmentation="randaugment",
)

# Unfreeze last 2 stages, add MixUp + CutMix and callbacks
model.unfreeze(layers=2)
model.train(
    "./my_images",
    epochs=10,
    batch_size=32,
    lr={"backbone": 1e-4, "head": 5e-4},
    class_weights="balanced",
    mixup_alpha=0.2,
    ema=True,
    callbacks=[
        EarlyStopping(monitor="val_loss", patience=3),
        CSVLogger(log_dir="./logs", filename="transfer.csv"),
    ],
)
```
