## End-to-End ViT Recipe

```python
from kitepy import Transformer

# Create pretrained ViT-Tiny adapted for 10 CIFAR-10 classes
vit = Transformer("vit_tiny", pretrained=True, num_classes=10)

# Stage 1: Freeze encoder backbone & train classifier head cleanly
vit.freeze_backbone()
vit.train(
    "cifar10",
    epochs=2,
    batch_size=64,
    lr={"backbone": 1e-4, "head": 1e-3},
)

# Stage 2: Unfreeze last 2 transformer blocks with EMA & warmup
vit.unfreeze(layers=2)
vit.train(
    "cifar10",
    epochs=3,
    batch_size=64,
    lr=3e-4,
    warmup_steps=0.1,
    ema=True,
)
```
