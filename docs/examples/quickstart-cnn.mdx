## End-to-End Script

```python
from kitepy import CNN

# 1. Initialize and train ResNet-18 on CIFAR-10
model = CNN("resnet18")
model.train(
    "cifar10",
    epochs=5,
    batch_size=128,
    lr=1e-3,
    ema=True,
    checkpoint_dir="./checkpoints/cifar10_cnn",
)

# 2. Evaluate on the test split
metrics = model.evaluate("cifar10")
print("Evaluation:", metrics)

# 3. Profile latency and throughput
stats = model.profile(input_size=(1, 3, 32, 32))
print("Profile:", stats)

# 4. Save pickle-free SafeTensors bundle & reload cleanly
model.save("./artifacts/resnet18_cifar10.safetensors", safe=True)
reloaded = CNN.load("./artifacts/resnet18_cifar10.safetensors")

# 5. Inspect predictions
import torch
sample = torch.randn(1, 3, 32, 32)
print("Top-3:", reloaded.predict(sample, top_k=3))
```
