## Compare Three Backbones With `compare()`

```python
from kitepy import compare

results = compare(
    ["resnet18", "mobilenet_v3_small", "convnext_tiny"],
    data="cifar10",
    epochs=2,
    batch_size=128,
    lr=1e-3,
    ema=True,
    save_every_n_epochs=0,
)

for r in results:
    print(r["model"], r["params"], f"{r['val_acc']:.2f}%", f"{r['latency_ms']:.2f}ms")
```

## High-Accuracy CIFAR Recipe (Nested YAML)

```yaml cifar100_config.yaml
model:
  num_classes: 100
  pretrained: true

data:
  augmentation: randaugment
  img_size: 32

training:
  epochs: 30
  batch_size: 128
  lr: 0.001
  optimizer: adamw
  scheduler: cosine
  warmup_steps: 0.1
  weight_decay: 0.05
  label_smoothing: 0.1
  mixup_alpha: 0.2
  ema: true
  csv_log_dir: ./logs/cifar100
```

```python
from kitepy import CNN

CNN("resnet50", config="cifar100_config.yaml").train("cifar100")
```
