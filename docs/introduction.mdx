## What is KitePy?

**KitePy** (`0.2.1`) is a modular PyTorch framework built on a single layered design: one-line training out of the box, with full engineering control over configs, task adapters, custom training steps, execution planning, and safe deployment underneath.

```python
from kitepy import CNN

CNN("resnet18").train("cifar10")
```

## Six Domain Pillars, One Unified Contract

Every model class in KitePy inherits from `BaseModel` and runs on the same `Engine` + `TaskAdapter` runtime:

| Pillar | Public APIs | Supported Backends & Tasks |
|--------|-------------|----------------------------|
| **Vision** | `CNN`, `Transformer`, `Vision` | 800+ `timm` models, `SimpleUNet`, `TinyDetector`, `torchvision` segmentation/detection (`classification`, `binary`, `multilabel`, `regression`, `segmentation`, `detection`) |
| **Language** | `LLM`, `TextClassifier` | Built-in `TinyGPT` + HuggingFace `AutoModelForCausalLM` / `AutoModelForSequenceClassification` with PEFT or built-in LoRA (`causal_lm`, `sequence_classification`) |
| **Multimodal** | `VLM` | Built-in `DualEncoderCLIP` + HuggingFace `CLIPModel` / `CLIPProcessor` for contrastive training and zero-shot image-text scoring |
| **Audio** | `Audio` | Built-in `AudioCNN` & `AudioTransformer` (automatic log-STFT spectrograms from waveforms) + HuggingFace `AutoModelForAudioClassification` |
| **Tabular** | `Tabular` | `TabularResNet` & `TabularMLP` for CSVs, NumPy arrays, Tensor tuples, and classification or regression |
| **Generative** | `Generative` | `ConvVAE`, `SimpleDDPM`, and optional `diffusers` `UNet2DModel` with `.sample(n)` |

## Quick Glance Across Modalities

<CodeGroup>
```python Vision (CNN & Multi-Task)
from kitepy import CNN, Vision

CNN("resnet18").train("./my_images", epochs=10)
preds = Vision(task="segmentation", model="unet", num_classes=3).train("synthetic", epochs=2)
```

```python Language (LoRA Fine-Tuning)
from kitepy import LLM

llm = LLM("Qwen/Qwen2.5-0.5B", pretrained=True, lora=True)
llm.train("chat.jsonl", epochs=3, auto_plan=True)
print(llm.generate("Summarize KitePy:", max_new_tokens=40))
```

```python Tabular & Audio
from kitepy import Tabular, Audio

Tabular("tabular_resnet", task="regression").train("housing.csv", epochs=15)
Audio("audio_transformer").train("./audio_classes", epochs=10)
```

```python Multimodal & Generative
from kitepy import VLM, Generative

vlm = VLM("clip_tiny").train("pairs.jsonl", epochs=5)
probs = vlm.predict("dog.jpg", texts=["a photo of a dog", "a car"])

gen = Generative("vae_small").train("synthetic", epochs=5)
images = gen.sample(n=4)
```
</CodeGroup>
