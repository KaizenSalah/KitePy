## Prerequisites

- Python `>= 3.8`
- PyTorch `>= 2.0.0`
- Optional GPU with CUDA or Apple Silicon MPS (`devices="auto"` selects automatically)

## Install

```bash
pip install kitepy
```

For HuggingFace LLMs, datasets, FastAPI serving, and SafeTensors bundles, add the optional extras or packages you need:

```bash
pip install "kitepy[all]" safetensors fastapi uvicorn peft
```

## 1. One-Line Vision Training

Train ResNet-18 on CIFAR-10 in two lines:

```python
from kitepy import CNN

model = CNN("resnet18").train("cifar10", epochs=5)
```

Using your own folder of class subdirectories (`my_data/dog/*.jpg`, `my_data/cat/*.jpg`) auto-detects `num_classes` and `class_names` and splits train/validation cleanly without leaking training augmentations into validation:

```python
model = CNN("resnet18", pretrained=True).train("./my_data", epochs=10, batch_size=64)
preds = model.predict("test_dog.jpg", top_k=3)
print(preds)
# [{'class_id': 1, 'label': 'dog', 'confidence': 0.94}, ...]
```

## 2. All Six Pillars at a Glance

Every pillar uses `.train()`, `.evaluate()`, `.predict()`, `.save()`, and `.load()`:

<CodeGroup>
```python Vision Tasks
from kitepy import Vision

# Tasks: "classification", "binary", "multilabel", "regression", "segmentation", "detection"
seg = Vision(task="segmentation", model="unet", num_classes=3)
seg.train("synthetic", epochs=2, img_size=64)

det = Vision(task="detection", model="tiny_detector", num_classes=4)
det.train("synthetic", epochs=2, img_size=64)
```

```python LLM & TextClassifier
from kitepy import LLM, TextClassifier

# Offline char-level GPT
llm = LLM("tiny_gpt", context_length=128)
llm.train(["kitepy simplifies pytorch training", "deep learning across modalities"], epochs=5)
print(llm.generate("kitepy", max_new_tokens=20, temperature=0.7))

# Pretrained HuggingFace LLM + LoRA on ChatML/JSONL
# hf_llm = LLM("Qwen/Qwen2.5-0.5B", pretrained=True, lora=True).train("chat.jsonl", epochs=3)

clf = TextClassifier("tiny_gpt", num_classes=2)
clf.train("synthetic", epochs=2)
```

```python Tabular
from kitepy import Tabular

# CSV expects target in the last column; NaNs and categorical features are handled automatically
reg = Tabular("tabular_resnet", task="regression").train("housing.csv", epochs=15)
clf = Tabular("tabular_mlp", task="classification").train("iris.csv", epochs=15)
```

```python Audio & Multimodal & Generative
from kitepy import Audio, VLM, Generative

au = Audio("audio_cnn").train("synthetic", epochs=2)  # or "./audio_folder" of .wav files
probs = VLM("clip_tiny").train("synthetic", epochs=2).predict("synthetic_or_image.png", texts=["cat", "dog"])

gen = Generative("vae_small", img_size=32).train("synthetic", epochs=2)
samples = gen.sample(n=4)  # Tensor of shape (4, 3, 32, 32)
```
</CodeGroup>

<Tip>
You can pass `data="synthetic"` to any pillar to run an instant zero-download end-to-end smoke check.
</Tip>

## 3. Scaling Up: Config Files & Power-User Controls

When you move beyond prototypes, combine typed configs, YAML files, `auto_plan=True`, callbacks, and custom steps:

```python
from kitepy import CNN, EarlyStopping, ModelCheckpoint, CSVLogger

model = CNN("vit_tiny", pretrained=True, num_classes=10)
model.freeze_backbone()

model.train(
    data="cifar10",
    epochs=10,
    lr={"backbone": 1e-4, "head": 1e-3},
    ema=True,
    mixup_alpha=0.2,
    auto_plan=True,
    memory_budget_mb=4096,
    safe_serialization=True,
    callbacks=[
        EarlyStopping(monitor="val_loss", patience=3),
        ModelCheckpoint(filepath="ckpts/ep_{epoch:02d}_{val_loss:.4f}.pt", save_top_k=2),
        CSVLogger(log_dir="./logs"),
    ],
)
```

## 4. Save Safely & Serve Over FastAPI

```python
# Recommended: pickle-free .safetensors + .meta.json + .yaml
model.save("artifacts/model.safetensors", safe=True)

from kitepy import CNN
reloaded = CNN.load("artifacts/model.safetensors")

# Instant FastAPI app with GET /health and POST /predict
app = reloaded.to_fastapi()
```

Or run the CLI directly from your terminal:

```bash
kitepy doctor
kitepy models all
kitepy predict artifacts/model.safetensors sample.png --modality vision --top-k 3
```
