## Overview

`CNN` provides a unified interface for image classification over KitePy's built-in presets, any model in `timm`, or any custom `torch.nn.Module`. Model names are validated eagerly at construction with close-match typo suggestions via `validate_vision_model_name()`.

```python
from kitepy import CNN

model = CNN("resnet18").train("cifar10")
```

## Simple vs. Advanced Usage

<CodeGroup>
```python Minimal (1-Liner)
from kitepy import CNN

CNN("resnet18").train("cifar10", epochs=5)
```

```python Custom Folder + Inference
from kitepy import CNN

model = CNN("convnext_tiny", pretrained=True)
model.train("./datasets/flowers", epochs=15, batch_size=32, ema=True)

preds = model.predict("daisy.jpg", top_k=3)
# [{'class_id': 0, 'label': 'daisy', 'confidence': 0.91}, ...]
```

```python Full CNNConfig + Augmentation
from kitepy import CNN, CNNConfig

cfg = CNNConfig(
    arch="resnet",
    depth=50,
    num_classes=100,
    in_channels=3,
    pretrained=True,
    drop_rate=0.2,
    drop_path_rate=0.1,
    freeze_backbone=False,
)

model = CNN("resnet50", config=cfg)
model.train(
    "cifar100",
    epochs=30,
    batch_size=64,
    lr=5e-4,
    augmentation="randaugment",
    mixup_alpha=0.2,
    label_smoothing=0.1,
)
```

```python Custom PyTorch nn.Module
import torch.nn as nn
from kitepy import CNN

net = nn.Sequential(
    nn.Conv2d(3, 32, 3, padding=1),
    nn.ReLU(),
    nn.AdaptiveAvgPool2d(1),
    nn.Flatten(),
    nn.Linear(32, 10),
)

model = CNN(net)
model.train("synthetic", img_size=32, epochs=2)
```
</CodeGroup>

## Built-In `CNN_PRESETS` & Aliases

| Family | Preset Names |
|--------|--------------|
| **ResNet** | `resnet18`, `resnet34`, `resnet50`, `resnet101`, `resnet152` |
| **Wide ResNet** | `wide_resnet50`, `wide_resnet101` (mapped to `wide_resnet50_2`, `wide_resnet101_2` in `timm`) |
| **ResNeXt** | `resnext50`, `resnext101` (mapped to `resnext50_32x4d`, `resnext101_32x8d` in `timm`) |
| **EfficientNet** | `efficientnet_b0` through `efficientnet_b7` |
| **EfficientNetV2** | `efficientnetv2_s`, `efficientnetv2_m`, `efficientnetv2_l` (`tf_efficientnetv2_*` in `timm`) |
| **MobileNet** | `mobilenet_v2` (`mobilenetv2_100`), `mobilenet_v3_small` (`mobilenetv3_small_100`), `mobilenet_v3_large` (`mobilenetv3_large_100`) |
| **VGG** | `vgg11`, `vgg13`, `vgg16`, `vgg19` |
| **DenseNet** | `densenet121`, `densenet169`, `densenet201` |
| **ConvNeXt** | `convnext_tiny`, `convnext_small`, `convnext_base`, `convnext_large` |

Any other model ID available in `timm.list_models()` (for example `"regnetx_016"`, `"eva02_tiny_patch14_224"`) also works directly. Check programmatically with `list_models("cnn")` or `list_timm_models()`.

## Real-World Prediction Inputs

`_VisionMixin._preprocess_input()` accepts all of the following in `.predict(inputs, return_probs=False, top_k=None)`:
- `torch.Tensor` `(B, C, H, W)` or single `(C, H, W)`
- `np.ndarray` `(B, C, H, W)`, `(H, W, C)`, or grayscale `(H, W)`
- `PIL.Image.Image`
- Image file path (`str` or `pathlib.Path`)
- A Python `list` of paths, PIL Images, NumPy arrays, tensors, or nested numeric pixel lists (JSON payloads)

Images loaded from file paths, PIL, or HWC NumPy arrays automatically apply validation transforms (`get_val_transforms(img_size, grayscale=(in_channels == 1))`).
