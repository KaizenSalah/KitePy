## Overview

KitePy separates **per-image transforms** (configured via `DataConfig.augmentation`) from **batch-level mixing** (`TrainingConfig.mixup_alpha` and `TrainingConfig.cutmix_alpha`).

---

## Image Augmentation Strategies (`augmentation`)

Pass `augmentation=...` to `.train()`, `DataConfig`, or YAML (`data.augmentation`):

| Strategy | Pipeline Applied |
|---|---|
| `"none"` | `Resize((img_size, img_size))`, `ToTensor()`, `Normalize(...)` |
| `"light"` / `"auto"` (default) | `RandomResizedCrop(img_size)`, `RandomHorizontalFlip()`, `ToTensor()`, `Normalize(...)` |
| `"heavy"` | `RandomResizedCrop(img_size)`, `RandomHorizontalFlip()`, `ColorJitter(0.4, 0.4, 0.4)`, `RandomRotation(15)`, `ToTensor()`, `Normalize(...)` |
| `"randaugment"` | `RandomResizedCrop(img_size)`, `RandomHorizontalFlip()`, `RandAugment(num_ops=2, magnitude=9)`, `ToTensor()`, `Normalize(...)` |
| `"trivialaugment"` | `RandomResizedCrop(img_size)`, `RandomHorizontalFlip()`, `TrivialAugmentWide()`, `ToTensor()`, `Normalize(...)` |
| `"autoaugment"` | `RandomResizedCrop(img_size)`, `RandomHorizontalFlip()`, `AutoAugment(IMAGENET)`, `ToTensor()`, `Normalize(...)` |

For RGB inputs, normalization uses ImageNet mean/std (`[0.485, 0.456, 0.406]`, `[0.229, 0.224, 0.225]`). For grayscale (`grayscale=True`), normalization uses `[0.5]`, `[0.5]`. Validation and `.predict()` always use `get_val_transforms()` (`Resize` + `ToTensor` + `Normalize`) with zero stochastic augmentation.

```python
from kitepy import CNN

CNN("resnet18").train("cifar10", epochs=20, augmentation="trivialaugment")
```

You can also use the transform helpers directly with custom PyTorch `Dataset`s:

```python
from kitepy import get_train_transforms, get_val_transforms

train_tf = get_train_transforms(img_size=224, augmentation="randaugment")
val_tf = get_val_transforms(img_size=224)
```

## Batch Regularization: MixUp & CutMix

Enable MixUp or CutMix directly via `TrainingConfig` parameters (`mixup_alpha`, `cutmix_alpha`):

- Active when `inputs.ndim == 4` (images) and `targets.ndim == 1` (class indices).
- Converts integer targets into smooth one-hot soft labels (`num_classes` inferred from classifier/dataset).
- If both `mixup_alpha > 0` and `cutmix_alpha > 0` are set, each batch picks CutMix or MixUp with 50% probability.
- Compatible with `ClassificationAdapter`, which handles 2D floating-point soft targets cleanly during accuracy tracking (`targets.argmax(dim=1)`).

```python
model = CNN("convnext_tiny", pretrained=True)
model.train(
    "./my_dataset",
    epochs=25,
    augmentation="randaugment",
    mixup_alpha=0.2,
    cutmix_alpha=1.0,
)
```
