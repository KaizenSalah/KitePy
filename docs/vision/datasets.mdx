## Overview

Any argument passed to `model.train(data)` or `BaseModel.evaluate(data)` resolves automatically through `load_vision_data_with_meta()` or `DataLoader` handling.

---

## Supported Data Inputs

### 1. Built-In Presets (`DATASET_PRESETS`)

| Name | Source | Classes | Default `img_size` | Channels | Notes |
|---|---|---|---|---|---|
| `"cifar10"` | `torchvision` | `10` | `32` | `3` | Auto-downloads to `data_dir`, populates `class_names` |
| `"cifar100"` | `torchvision` | `100` | `32` | `3` | Auto-downloads to `data_dir`, populates `class_names` |
| `"mnist"` | `torchvision` | `10` | `28` | `1` | Auto-converts grayscale to 3ch RGB unless `in_channels=1` |
| `"fashion_mnist"` / `"fashion-mnist"` | `torchvision` | `10` | `28` | `1` | Auto-converts grayscale to 3ch RGB unless `in_channels=1` |
| `"imagenet"` / `"imagenet-1k"` | local | auto | `224` | `3` | Expects `<data_dir>/imagenet/{train,val}` |
| `"synthetic"` | in-memory | configurable | configurable | configurable | Adapts to task (`classification`, `binary`, `multilabel`, `regression`, `segmentation`, `detection`) |

### 2. Custom `ImageFolder` Directory

Point `.train()` directly at a folder on disk. All three common layouts work automatically:

<CodeGroup>
```text Pre-Split (train / val / test)
my_dataset/
├── train/
│   ├── cat/ ...
│   └── dog/ ...
├── val/
│   ├── cat/ ...
│   └── dog/ ...
└── test/        # optional
    └── ...
```

```text Train-Only (Auto-Split Val)
my_dataset/
└── train/
    ├── cat/ ...
    └── dog/ ...
```

```text Unsplit Root (Auto-Split Train/Val)
my_dataset/
├── cat/ ...
└── dog/ ...
```
</CodeGroup>

```python
model = CNN("resnet18", pretrained=True).train("./my_dataset", epochs=10, val_split=0.2)
print(model.config.num_classes)  # Auto-detected: 2
print(model.class_names)         # ['cat', 'dog']
```

<Note>
**Zero augmentation leakage**: when splitting a folder without an explicit `val/` directory, `_load_custom_folder()` constructs two independent `datasets.ImageFolder` instances (`train_transform` vs `val_transform`) before indexing `Subset`s, so validation images never receive training random crops or flips.
</Note>

### 3. HuggingFace Hub Vision Datasets (`hf://...`)

```python
# Expects "image" and "label" columns (requires `pip install datasets`)
CNN("resnet18", pretrained=True).train("hf://beans", epochs=5)
```

### 4. PyTorch `Dataset` & `DataLoader` Inputs

```python
# Any PyTorch Dataset (auto-split 80/20 via val_split if len >= 5)
model.train(my_torch_dataset, epochs=5, batch_size=32)

# Single DataLoader (optionally pass val_data=val_loader)
model.train(train_loader, val_data=val_loader, epochs=5)

# Explicit loader tuples
model.train((train_loader, val_loader), epochs=5)
model.train((train_loader, val_loader, test_loader), epochs=5)
```

## Controlling `data_dir` and Splits

```python
model.train(
    "cifar10",
    data_dir="./datasets",
    img_size=64,
    val_split=0.15,
    shuffle=True,
    drop_last=False,
)
```
