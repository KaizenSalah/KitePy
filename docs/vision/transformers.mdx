## Overview

`Transformer` provides access to Vision Transformer architectures (`ViT`, `DeiT`, `Swin`, and any compatible `timm` transformer) with the same `.train()`, `.evaluate()`, `.predict()`, `.freeze_backbone()`, and `.unfreeze()` interface as `CNN`.

```python
from kitepy import Transformer

Transformer("vit_tiny", pretrained=True).train("cifar10", epochs=5)
```

## Simple vs. Transfer Learning Workflow

<CodeGroup>
```python Quick Fine-Tune
from kitepy import Transformer

vit = Transformer("vit_tiny", pretrained=True, num_classes=10)
vit.train("cifar10", epochs=5, batch_size=64, lr=3e-4, warmup_steps=0.1)
```

```python Differential LR + Gradual Unfreeze
from kitepy import Transformer

vit = Transformer("vit_tiny", pretrained=True, num_classes=10)

# Head-only warmup using timm.get_classifier() (keeps blocks.*.mlp.fc1/fc2 frozen!)
vit.freeze_backbone()
vit.train(
    "cifar10",
    epochs=2,
    batch_size=64,
    lr={"backbone": 1e-4, "head": 1e-3},
)

# Unfreeze final 2 encoder blocks and continue fine-tuning with EMA
vit.unfreeze(layers=2)
vit.train("cifar10", epochs=2, batch_size=64, lr=3e-4, ema=True)
```

```python Full TransformerConfig
from kitepy import Transformer, TransformerConfig

cfg = TransformerConfig(
    arch="vit",
    img_size=224,
    patch_size=16,
    embed_dim=384,
    depth=12,
    num_heads=6,
    mlp_ratio=4.0,
    num_classes=100,
    pretrained=True,
    drop_rate=0.1,
    attn_drop_rate=0.0,
    drop_path_rate=0.1,
)

model = Transformer("vit_small", config=cfg).train("cifar100", epochs=15, batch_size=64)
```
</CodeGroup>

## Why `freeze_backbone()` Is ViT-Safe

Naive string checks like `"fc" in name` break Vision Transformers because every ViT MLP block contains `blocks.*.mlp.fc1` and `blocks.*.mlp.fc2`. KitePy's `get_head_parameter_names()` inspects `model.get_classifier()` (when available via `timm`) and exact head attributes (`head`, `classifier`, `fc`, `lm_head`, `score`, `last_linear`), keeping encoder MLP weights properly frozen while leaving the classification head trainable.
