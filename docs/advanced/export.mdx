## Save & Load

```python
from kitepy import CNN

model = CNN("resnet18", num_classes=10).train("cifar10", epochs=2)

# Safe SafeTensors bundle (recommended) + YAML config
model.save("resnet18.safetensors", save_config=True, safe=True)
reloaded = CNN.load("resnet18.safetensors")

# Standard weights_only-compatible PyTorch bundle
model.save("resnet18.pt", save_config=True, safe=False)
reloaded_pt = CNN.load("resnet18.pt", device="cpu")
```

For full security guarantees and custom-module handling (`custom_model=...`, `allow_unsafe=False`), see [Serialization & Security](/advanced/serialization-and-security).

## `model.export()`

```python
model.export(
    path: Union[str, Path],
    format: str = "auto",
    input_shape: Optional[Tuple[int, ...]] = None,
    verify: bool = False,
) -> self
```

### Supported Formats

- `format="auto"` infers from extension: `.onnx` → `"onnx"`, `.safetensors` → `"safetensors"`, anything else → `"torchscript"`.
- `format="torchscript"`: Traces `self.model` via `torch.jit.trace(self.model, torch.randn(*shape))`. Pass `verify=True` to load the traced file back and print max output diff against the PyTorch model.
- `format="onnx"`: Temporarily moves model to CPU (restoring `original_device` in `finally`), exports using `opset_version=14`, `do_constant_folding=True`, dynamic batch axes on `input` / `output`, and `dynamo=False` when supported by the installed PyTorch version. Requires `onnx`.
- `format="safetensors"`: Exports contiguous CPU weights via `safetensors.torch.save_file()`.

If `input_shape` is `None`, KitePy calls `_default_input_shape()` (uses `last_input_shape` if previously predicted, `(1, input_dim)` on `Tabular`, or `(1, in_channels, img_size, img_size)`).

<CodeGroup>
```python TorchScript + Parity Check
model.export("deploy/resnet18_ts.pt", format="torchscript", input_shape=(1, 3, 32, 32), verify=True)
```

```python ONNX Export
model.export("deploy/resnet18.onnx", format="onnx", input_shape=(1, 3, 32, 32))
```

```python Weights-Only SafeTensors
model.export("deploy/resnet18_weights.safetensors", format="safetensors")
```
</CodeGroup>

## Dynamic INT8 Quantization (`quantize`)

```python
model.quantize(bits: int = 8) -> self
```

When `bits == 8`, runs PyTorch dynamic quantization (`torch.ao.quantization.quantize_dynamic` / `torch.quantization.quantize_dynamic`) over `{nn.Linear, nn.Conv2d}` with `dtype=torch.qint8` for faster CPU inference. Other bit-widths print an advisory message noting specialized libraries such as `bitsandbytes`.

## HuggingFace Hub (`push_to_hub`)

Push checkpoint weights, `.yaml` config, and auto-generated `README.md` model card directly to a HuggingFace Hub repository (`pip install huggingface_hub`):

```python
url = model.push_to_hub(
    repo_id="username/my-kitepy-model",
    commit_message="Upload KitePy model",
    private=False,
    token=None,
)
```
