## Model Inspection (`describe()`, `summary()`, `explain_config()`)

```python
from kitepy import CNN

model = CNN("resnet18", num_classes=10)
model._build_model()

model.summary()          # Parameter count (total, trainable, non-trainable), MB size, architecture print
model.describe()         # Metadata + config JSON + architecture summary
model.explain_config()   # Full JSON schema of every overridable option on this pillar's config class
```

## Latency & Throughput Profiling (`profile()`)

```python
stats = model.profile(input_size=(1, 3, 224, 224))
print(stats)
```

Runs 3 warmup passes + 10 timed forward passes with `torch.no_grad()` on `self.device` (defaults to `(1, input_dim)` on `Tabular` or `(1, in_channels, img_size, img_size)` otherwise if `input_size=None`). Returns:

```python
{
    "total_params": 11181642,
    "trainable_params": 11181642,
    "model_size_mb": 42.69,
    "latency_ms": 2.66,
    "throughput": 375.6,  # samples/sec
}
```

## Side-by-Side Model Benchmarking (`compare()`)

`compare()` trains, profiles, and prints a comparison table across multiple model names or instantiated `BaseModel` objects on the same dataset:

```python
from kitepy import compare, Tabular

# Compare CNN presets
results = compare(
    ["resnet18", "mobilenet_v3_small", "convnext_tiny"],
    data="cifar10",
    epochs=2,
    batch_size=128,
)

# Compare across another pillar class via cls=
tab_results = compare(
    ["tabular_mlp", "tabular_resnet"],
    data="synthetic",
    epochs=3,
    cls=Tabular,
)
```

Each returned dict contains `"model"`, `"params"`, `"size_mb"`, `"latency_ms"`, `"train_loss"`, `"val_loss"`, `"val_acc"`, `"train_time_s"`, and `"instance"` (the trained model).

## Memory Utilities

```python
from kitepy.core.utils import get_memory_usage, clear_gpu_memory

print(get_memory_usage())  # {'cpu_memory_mb': 0, 'gpu_memory_mb': ..., 'gpu_memory_reserved_mb': ...}
clear_gpu_memory()         # Calls torch.cuda.empty_cache() if CUDA is available
```
