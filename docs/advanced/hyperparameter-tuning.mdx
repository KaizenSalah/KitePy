## Learning Rate Finder (`find_lr` & `LRFinder`)

`BaseModel.find_lr()` runs a Leslie-Smith style LR Range Test over an exponential grid (`1e-7` to `10.0` over `100` steps by default) using the model's exact configured task loss and `TaskAdapter`, then restores the initial model and optimizer weights cleanly in a `try...finally` block.

<CodeGroup>
```python Standalone Inspection
from kitepy import CNN

model = CNN("resnet18", num_classes=10)
suggested_lr = model.find_lr("cifar10", batch_size=64)
print(f"Suggested LR: {suggested_lr:.2e}")

model.train("cifar10", epochs=10, lr=suggested_lr)
```

```python Inline During Training
from kitepy import CNN

# Runs LRFinder automatically right before Engine starts epochs
CNN("resnet18").train("cifar10", epochs=10, lr="auto")
```

```python Direct LRFinder Control + Plotting
from kitepy import LRFinder

finder = LRFinder(model, optimizer, criterion, device, adapter=adapter)
lrs, losses = finder.find(train_loader, min_lr=1e-7, max_lr=1.0, num_steps=100, beta=0.98)
best_lr = finder.suggest_lr(skip_start=10, skip_end=5)
finder.plot("lr_curve.png")  # Requires matplotlib
```
</CodeGroup>

## Automated Hyperparameter Search (`tune()`)

Requires `pip install optuna`:

```python
from kitepy import CNN

model = CNN("resnet18", pretrained=True)
best_params = model.tune("cifar10", trials=10, epochs=3)
print(best_params)  # {'lr': ..., 'batch_size': ..., 'weight_decay': ...}
```

### Optuna Objective Details

Inside each Optuna trial (`direction="minimize"`), `BaseModel.tune(data, trials=20, **kwargs)` samples:
- `lr`: `trial.suggest_float("lr", 1e-5, 1e-2, log=True)`
- `batch_size`: `trial.suggest_categorical("batch_size", [16, 32, 64, 128])`
- `weight_decay`: `trial.suggest_float("weight_decay", 1e-5, 1e-2, log=True)`

It clones `self`, trains with `fast_dev_run=False` for `kwargs.get("epochs", 3)` epochs (forwarding all additional kwargs), minimizes the lowest recorded `val_loss` (or `train_loss` if no validation split exists), and returns `study.best_params`.
