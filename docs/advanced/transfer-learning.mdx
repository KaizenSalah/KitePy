## Freeze & Unfreeze Workflow

`BaseModel.freeze_backbone()` and `BaseModel.unfreeze()` make multi-stage transfer learning simple and safe for both CNNs and Vision Transformers:

```python
from kitepy import Transformer

vit = Transformer("vit_tiny", pretrained=True, num_classes=10)

# Stage 1: Freeze all non-head parameters (keeps head trainable)
vit.freeze_backbone()
vit.train("cifar10", epochs=3, batch_size=64, lr=1e-3)

# Stage 2: Unfreeze last 2 transformer blocks with differential learning rates
vit.unfreeze(layers=2)
vit.train("cifar10", epochs=5, batch_size=64, lr={"backbone": 1e-4, "head": 1e-3})
```

### Selective Unfreezing Signatures

```python
model.unfreeze()                    # Unfreeze all parameters
model.unfreeze(layers=3)            # Unfreeze the last 3 logical blocks/modules (via get_module_blocks)
model.unfreeze(pattern="layer4")    # Unfreeze every parameter whose name contains "layer4"
```

## Differential Learning Rates & Layer Decay

Instead of one global LR, you can apply:
- **Dict LR**: `lr={"backbone": 1e-4, "head": 1e-3}` (head parameters are resolved via `get_head_parameter_names()`).
- **Backbone multiplier**: `lr=1e-3, backbone_lr_mult=0.1` (`head=1e-3`, `backbone=1e-4`).
- **Layer-wise decay**: `lr=1e-3, layer_decay=0.75` decays learning rates exponentially across deeper layers and assigns the lowest LR to stem/embeddings.

## LoRA for Language Models (`lora=True`)

```python
from kitepy import LLM

llm = LLM("Qwen/Qwen2.5-0.5B", pretrained=True, lora=True, lora_r=8, lora_alpha=16, lora_dropout=0.05)
llm.train("chat.jsonl", epochs=3, lr=2e-4)
```

Uses HuggingFace `peft` when installed and falls back automatically to `apply_builtin_lora()` (`LoRALinear`).
