## `BaseConfig` & Helpers

Every config dataclass inherits from `BaseConfig`:

- `to_dict() -> Dict[str, Any]`
- `to_yaml(path: str)` / `to_json(path: str)` (atomic writes)
- `field_names() -> set`
- `from_dict(config_dict, strict: bool = True)` (typo suggestions with `strict=True`)
- `from_yaml(path: str, strict: bool = True)` / `from_json(path: str, strict: bool = True)`

### Helpers

- `merge_configs(default, preset=None, user_config=None, strict=False, **kwargs)` — priority: `kwargs > user_config > preset > default`.
- `split_kwargs(kwargs, model_config_cls) -> (model_kw, data_kw, train_kw, unknown_kw)`
- `validate_config(config)`
- `auto_batch_size(model_size: str, available_memory_gb: float) -> int` (`small=128`, `base=64`, `large=32`, `xlarge=16` scaled by `gb / 24.0`)
- `auto_learning_rate(batch_size: int, base_lr: float = 1e-3) -> float` (`base_lr * (batch_size / 256)`)

## `ExperimentConfig`

Combines `model: ModelConfig`, `training: TrainingConfig`, and `data: DataConfig`:

| Field | Type | Default |
|---|---|---|
| `model` | `ModelConfig` | `CNNConfig()` |
| `training` | `TrainingConfig` | `TrainingConfig()` |
| `data` | `DataConfig` | `DataConfig()` |
| `experiment_name` | `str` | `"default_experiment"` |
| `tags` | `list` | `[]` |
| `notes` | `str` | `""` |
| `use_wandb` | `bool` | `False` |
| `wandb_project` | `Optional[str]` | `None` |
| `wandb_entity` | `Optional[str]` | `None` |
