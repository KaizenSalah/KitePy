## Overview

`DataConfig` controls data paths, automatic splits, dimensions/sequence limits, augmentation strategies, sampling, and streaming.

```python
from kitepy import DataConfig
```

---

## Fields

| Parameter | Type | Default | Description |
|---|---|---|---|
| `train_data` | `Optional[Any]` | `None` | Default training data source when `data=None` in `.train()` |
| `val_data` | `Optional[Any]` | `None` | Optional validation `DataLoader` |
| `test_data` | `Optional[Any]` | `None` | Optional test data reference |
| `data_dir` | `str` | `"./data"` | Root cache/download directory for torchvision/ImageNet datasets |
| `train_split` | `Union[str, float]` | `"train"` | Train split selector |
| `val_split` | `Union[str, float]` | `0.2` | Validation split fraction when auto-splitting folders, Datasets, CSVs, or manifests |
| `test_split` | `Union[str, float]` | `"test"` | Test split selector |
| `img_size` | `Optional[int]` | `None` | Target image size (auto-populated from model/dataset presets when `None`) |
| `in_channels` | `Optional[int]` | `None` | Input channels (auto-populated from model config when `None`) |
| `num_classes` | `Optional[int]` | `None` | Explicit class count override |
| `max_length` | `int` | `512` | Maximum sequence token length for `LLM` / `VLM` (clamped by `LLMConfig.context_length`) |
| `preprocessing` | `str` | `"auto"` | Preprocessing mode |
| `augmentation` | `str` | `"auto"` | Vision transform strategy: `"none"`, `"light"`, `"auto"`, `"heavy"`, `"randaugment"`, `"trivialaugment"`, `"autoaugment"` |
| `shuffle` | `bool` | `True` | Shuffle training batches |
| `drop_last` | `bool` | `False` | Drop last incomplete training batch |
| `streaming` | `bool` | `False` | Stream `.jsonl` / `.txt` files via constant-memory `StreamingJsonlDataset` (`IterableDataset`) |
| `buffer_size` | `int` | `10000` | Streaming shuffle buffer setting |

---

## Example

```python
from kitepy import CNN, DataConfig

cfg = DataConfig(
    data_dir="./datasets",
    val_split=0.15,
    augmentation="trivialaugment",
    img_size=64,
    shuffle=True,
    drop_last=False,
)

CNN("resnet18").train("cifar10", epochs=5, **cfg.to_dict())
```
