## Overview

`Vision` (`modality = "vision"`, `default_config_class = CNNConfig`) extends `_VisionMixin` and `BaseModel` with explicit task selection across 6 vision tasks.

```python
from kitepy import Vision
```

---

## Constructor

```python
Vision(
    task: str = "classification",
    model: Optional[Union[str, nn.Module]] = None,
    config: Optional[Union[Dict, CNNConfig, str]] = None,
    **kwargs,
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `task` | `str` | `"classification"` | One of `"classification"`, `"binary"`, `"multilabel"`, `"regression"`, `"segmentation"`, `"detection"` (`NotImplementedError` otherwise) |
| `model` | `Optional[Union[str, nn.Module]]` | `None` | Auto-resolves to `"unet"` (`segmentation`), `"tiny_detector"` (`detection`), or `"resnet18"` (all other tasks); also accepts `timm` models, `torchvision.models.segmentation.*`, `torchvision.models.detection.*`, or custom `nn.Module` |
| `config` | `Optional[Union[Dict, CNNConfig, str]]` | `None` | Config object, dict, or YAML/JSON path |
| `**kwargs` | `Any` | — | Additional config overrides |

## `Vision.TASK_DEFAULTS`

| Task | Adapter | Default Loss | Fallback `num_classes` (if unset) |
|---|---|---|---|
| `"classification"` | `"classification"` | `"cross_entropy"` | `1000` (auto-aligned to dataset) |
| `"binary"` | `"binary"` | `"bce"` | `1` |
| `"multilabel"` | `"multilabel"` | `"bce"` | auto-aligned / user-supplied |
| `"regression"` | `"regression"` | `"mse"` | `1` |
| `"segmentation"` | `"segmentation"` | `"cross_entropy"` | `2` |
| `"detection"` | `"detection"` | `"cross_entropy"` | `1000` / user-supplied |

## Built-In Helper Architectures (`kitepy.pillars.vision`)

### `SimpleUNet`

```python
SimpleUNet(in_channels: int = 3, num_classes: int = 2, base_ch: int = 32)
```
Lightweight U-Net with bilinear size alignment before decoding. Expects `(B, C, H, W)` inputs and returns `(B, num_classes, H, W)` pixel logits.

### `TinyDetector`

```python
TinyDetector(in_channels: int = 3, num_classes: int = 10, num_queries: int = 5)
```
Lightweight multi-slot detector following the torchvision detection interface:
- `train()`: `forward(images, targets)` returns `{"loss_box": smooth_l1, "loss_cls": cross_entropy}` (supervises up to `num_queries` boxes per image, plus class `0` background for unmatched/empty slots).
- `eval()`: `forward(images)` returns `[{"boxes": Tensor[N, 4], "labels": Tensor[N], "scores": Tensor[N]}, ...]`.

## Vision Data & Transform Helpers (`kitepy.pillars.vision`)

```python
from kitepy import (
    load_vision_data,
    load_data,  # alias for load_vision_data
    get_train_transforms,
    get_val_transforms,
)
from kitepy.pillars.vision.data import load_vision_data_with_meta
```

- **`load_vision_data_with_meta(dataset_name, data_config, train_config, download=True)`** → `(train_loader, val_loader, test_loader, metadata)`
- **`load_vision_data(...)` / `load_data(...)`** → backward-compatible 3-tuple `(train_loader, val_loader, test_loader)`
- **`get_train_transforms(img_size: int, augmentation: str = "auto", to_rgb: bool = False, grayscale: bool = False)`**
- **`get_val_transforms(img_size: int, to_rgb: bool = False, grayscale: bool = False)`**

## Examples

```python
from kitepy import Vision

seg = Vision(task="segmentation", model="unet", num_classes=3)
seg.train("synthetic", img_size=64, epochs=2, batch_size=4)
seg.save("seg.safetensors", safe=True)

reloaded = Vision.load("seg.safetensors")  # Preserves task="segmentation" and num_classes=3
```
