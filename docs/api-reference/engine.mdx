## `Engine`

Universal training loop powering all KitePy pillars, or usable directly with any raw PyTorch `nn.Module`.

```python
from kitepy import Engine, TrainingConfig
from kitepy.core.engine import FocalLoss, create_loss_function
```

---

## Constructor

```python
Engine(
    model: nn.Module,
    config: TrainingConfig,
    modality: str = "vision",
    adapter: Optional[TaskAdapter] = None,
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `model` | `nn.Module` | required | PyTorch module to train |
| `config` | `TrainingConfig` | required | Training configuration instance |
| `modality` | `str` | `"vision"` | Modality hint used if resolving default `TaskAdapter` |
| `adapter` | `Optional[TaskAdapter]` | `None` | Explicit adapter; resolved via `get_adapter(config.task, modality, config.train_step)` when omitted |

---

## Public Methods

### `train()`

```python
engine.train(
    train_loader: DataLoader,
    val_loader: Optional[DataLoader] = None,
) -> Tuple[nn.Module, List[Dict[str, Any]]]
```

- Raises `ValueError` if `train_loader` has `0` batches (`steps_per_epoch == 0` or `batches_run == 0`).
- Executes balanced class-weight calculation (`class_weights="balanced"`), auto LR finder, pre-flight `ExecutionPlanner`, `accelerate` preparation, checkpoint resume, epochs/steps, validation, scheduler updates, `ModelEMA`, callbacks, checkpoint saving, and early stopping.
- Returns `(self.model, self.history)` and populates `self.execution_report`.

### `evaluate()`

```python
engine.evaluate(test_loader: DataLoader) -> Dict[str, float]
```

Evaluates `self.model` via `_validate(test_loader)` and returns `{"test_loss": float, "test_<metric>": float, ...}` (includes `"test_accuracy"` if `"acc"` is present).

## Attributes

| Attribute | Type | Description |
|---|---|---|
| `model` | `nn.Module` | Trained (and unwrapped/EMA-copied after `.train()`) model |
| `config` | `TrainingConfig` | Active config |
| `adapter` | `TaskAdapter` | Active task adapter |
| `optimizer` | `torch.optim.Optimizer` | Configured optimizer |
| `scheduler` | `Optional[Any]` | Configured scheduler |
| `criterion` | `nn.Module` | Resolved loss function |
| `scaler` | `Optional[GradScaler]` | CUDA FP16 `GradScaler` when active |
| `ema` | `Optional[ModelEMA]` | EMA tracker when `config.ema=True` |
| `planner` | `ExecutionPlanner` | Pre-flight memory planner |
| `execution_plan` | `Optional[ExecutionPlan]` | Solved plan if enabled |
| `guard` | `RuntimeGuard` | OOM & NaN/Inf recovery tracker |
| `callbacks` | `CallbackList` | Registered callbacks |
| `device` | `torch.device` | Active execution device |
| `history` | `List[Dict[str, Any]]` | Per-epoch logged metrics |
| `global_step` | `int` | Completed optimizer updates |
| `best_val_loss` | `float` | Best observed `val_loss` |
| `execution_report` | `Dict[str, Any]` | Lineage, plan, recovery stats, epoch/step counts |
