## Overview

`Transformer` subclasses `_VisionMixin` and `BaseModel` (`modality = "vision"`, `default_config_class = TransformerConfig`, `default_task = "classification"`).

```python
from kitepy import Transformer
```

---

## Constructor

```python
Transformer(
    model: Optional[Union[str, nn.Module]] = "vit_base",
    config: Optional[Union[Dict, TransformerConfig, str]] = None,
    **kwargs,
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `model` | `Optional[Union[str, nn.Module]]` | `"vit_base"` | Preset (`vit_tiny/small/base/large/huge`, `deit_*`, `swin_*`), any `timm` transformer ID, or `nn.Module` |
| `config` | `Optional[Union[Dict, TransformerConfig, str]]` | `None` | `TransformerConfig`, `ExperimentConfig`, dictionary, or YAML/JSON file path |
| `**kwargs` | `Any` | — | Routed via `split_kwargs()` across `TransformerConfig`, `DataConfig`, and `TrainingConfig` |

## Examples

<CodeGroup>
```python Simple ViT Training
from kitepy import Transformer

Transformer("vit_tiny", pretrained=True, num_classes=10).train("cifar10", epochs=5, batch_size=64)
```

```python Transfer Learning Pipeline
from kitepy import Transformer

vit = Transformer("vit_tiny", pretrained=True, num_classes=10)
vit.freeze_backbone()
vit.train("cifar10", epochs=2, lr={"backbone": 1e-4, "head": 1e-3})
vit.unfreeze(layers=2)
vit.train("cifar10", epochs=3, lr=3e-4, ema=True)
```
</CodeGroup>
