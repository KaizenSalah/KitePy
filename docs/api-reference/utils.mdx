## Device & Reproducibility

- **`get_device(device="auto") -> torch.device`**: Handles `"auto"` (`cuda` -> `mps` -> `cpu`), integer GPU index, `"cpu"`, `"cuda"`, `"mps"`.
- **`get_num_gpus() -> int`**, **`get_gpu_memory(device=0) -> float`** (free GB)
- **`print_device_info()`**, **`print_version_info()`**
- **`set_seed(seed=42, deterministic=False)`**: Seeds `random`, `numpy`, `torch`, CUDA, and optionally enables deterministic algorithms + disables cuDNN benchmark.

---

## Transfer Learning & Optimizer Groups

- **`get_head_parameter_names(model: nn.Module) -> Set[str]`**: Uses `timm` `.get_classifier()`, head attributes (`head`, `classifier`, `fc`, `lm_head`, `score`, `last_linear`), or trailing module prefix.
- **`get_module_blocks(model: nn.Module) -> List[nn.Module]`**: Ordered backbone modules excluding head and parameterless layers.
- **`build_parameter_groups(model, lr, weight_decay=0.01, backbone_lr_mult=None, layer_decay=None)`**: Creates parameter groups with automatic weight decay exclusion (`bias`, `norm`, `bn`, `ln`, `layernorm`, `rmsnorm`, `ndim <= 1`).

## `ModelEMA`

```python
ema = ModelEMA(model: nn.Module, decay: float = 0.9999)
ema.update(model)
state = ema.state_dict()
ema.load_state_dict(state)
```

Maintains a detached, frozen `deepcopy` shadow model updated with warmup decay `min(decay, (1 + n) / (10 + n))` on floating-point parameters and exact buffer copy (`running_mean`, `running_var`).

## Summaries, Checkpoints & Memory

- `count_parameters(model, trainable_only=False) -> int`
- `get_model_size_mb(model) -> float`, `print_model_summary(model)`
- `get_checkpoint_path(checkpoint_dir, model_name, epoch, metric_name="loss", metric_value=0.0) -> str`
- `cleanup_old_checkpoints(checkpoint_dir, keep_top_k=3, metric_name="loss", lower_is_better=True)`
- `get_memory_usage() -> dict`, `clear_gpu_memory()`, `get_lr(optimizer) -> float`, `format_time(seconds) -> str`
