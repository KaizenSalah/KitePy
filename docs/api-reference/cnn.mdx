## Overview

`CNN` subclasses `_VisionMixin` and `BaseModel` (`modality = "vision"`, `default_config_class = CNNConfig`, `default_task = "classification"`).

```python
from kitepy import CNN
```

---

## Constructor

```python
CNN(
    model: Optional[Union[str, nn.Module]] = "resnet18",
    config: Optional[Union[Dict, CNNConfig, str]] = None,
    **kwargs,
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `model` | `Optional[Union[str, nn.Module]]` | `"resnet18"` | Preset name, any `timm` model ID, or custom `torch.nn.Module`. Validated eagerly via `validate_vision_model_name()`. |
| `config` | `Optional[Union[Dict, CNNConfig, str]]` | `None` | `CNNConfig`, `ExperimentConfig`, dictionary, or YAML/JSON file path |
| `**kwargs` | `Any` | — | Routed via `split_kwargs()` to `CNNConfig`, `DataConfig`, and `TrainingConfig` |

## Examples

<CodeGroup>
```python Preset One-Liner
from kitepy import CNN

CNN("resnet18").train("cifar10", epochs=5)
```

```python Config & Pretrained
from kitepy import CNN, CNNConfig

cfg = CNNConfig(num_classes=100, pretrained=True, drop_rate=0.2)
model = CNN("convnext_tiny", config=cfg).train("cifar100", epochs=20, ema=True)
```

```python Inference Across Formats
preds = model.predict("cat.jpg", top_k=3)
probs = model.predict(["a.jpg", "b.jpg"], return_probs=True)
```
</CodeGroup>
