## Registry Functions

- **`list_models(modality: str = "all")`** — Returns a dict of lists when `modality="all"`, or list of keys for `"vision"`, `"cnn"`, `"transformer"`, `"llm"`, `"language"`, `"vlm"`, `"multimodal"`, `"audio"`, `"tabular"`, `"generative"`, `"rnn"`.
- **`list_datasets(modality: str = "all")`** — Filters `DATASET_PRESETS` by `"all"`, `"vision"`, `"language"` / `"text"`, `"multimodal"`.
- **`get_preset(name: str, modality: Optional[str] = None) -> Dict[str, Any]`**
- **`register_preset(name: str, config: Dict[str, Any], modality: str, overwrite: bool = False)`**

```python
from kitepy import CNN, register_preset

register_preset(
    name="resnet101_wide",
    config={"arch": "resnet", "depth": 101, "width_multiplier": 2.0},
    modality="cnn",
)
model = CNN("resnet101_wide", num_classes=100)
```
