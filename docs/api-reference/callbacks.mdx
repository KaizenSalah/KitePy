## `Callback` (Base Class)

Hooks: `on_train_start(trainer, **kwargs)`, `on_train_end(trainer, **kwargs)`, `on_epoch_start(trainer, epoch, **kwargs)`, `on_epoch_end(trainer, epoch, metrics, **kwargs)`, `on_batch_start(trainer, batch_idx, **kwargs)`, `on_batch_end(trainer, batch_idx, loss, **kwargs)`, `on_validation_start(trainer, **kwargs)`, `on_validation_end(trainer, metrics, **kwargs)`.

---

## `EarlyStopping`

```python
EarlyStopping(
    monitor: str = "val_loss",
    patience: int = 5,
    min_delta: float = 1e-4,
    mode: str = "min",
)
```

Tracks `best_value`, `counter`, and `should_stop: bool`. Supports `"min"` and `"max"`.

---

## `ModelCheckpoint`

```python
ModelCheckpoint(
    filepath: str = "checkpoints/model_{epoch:02d}.pt",
    monitor: str = "val_loss",
    save_best_only: bool = False,
    save_top_k: int = 3,
    mode: str = "min",
)
```

- Formats `{epoch}`, `{val_loss}`, and `{train_loss}` in `filepath`.
- Falls back to `train_loss` if `metrics.get(self.monitor)` is `None`.
- Saves `epoch`, `global_step`, `best_val_loss`, `model_state_dict`, `optimizer_state_dict`, `metrics`, `history`.
- Ranks saved paths by monitored score so constant filepaths never self-delete and worst checkpoints are evicted first when `len > save_top_k`.

---

## `CSVLogger`

```python
CSVLogger(log_dir: str = "logs", filename: str = "metrics.csv")
```

Logs every epoch row; dynamically widens CSV header columns and rewrites earlier rows with `restval=""` whenever new metrics appear mid-run.

---

## `ProgressLogger` & `LRMonitor`

- **`ProgressLogger(log_every_n_steps: int = 50)`**: Prints running average loss every `log_every_n_steps` training batches.
- **`LRMonitor()`**: Prints `trainer.optimizer.param_groups[0]["lr"]` at each epoch end.

---

## `WandbLogger` & `TensorBoardLogger`

- **`WandbLogger(project: str = "kitepy", name: Optional[str] = None, config: Optional[Dict] = None)`** (`wandb.init`, `wandb.watch`, `wandb.log`, `wandb.finish`).
- **`TensorBoardLogger(log_dir: str = "runs")`** (uses `torch.utils.tensorboard.SummaryWriter.add_scalar`).

---

## `LambdaCallback` & `CallbackList`

```python
LambdaCallback(
    on_train_start=None,
    on_train_end=None,
    on_epoch_start=None,
    on_epoch_end=None,
    on_batch_start=None,
    on_batch_end=None,
    on_validation_start=None,
    on_validation_end=None,
)
```

`CallbackList(callbacks=None)` resolves shortcuts `"early_stopping"`, `"lr_monitor"`, `"progress"`, `"csv"`, `"tensorboard"`, `"wandb"`, and `"checkpoint"`, and exposes `.add()` and `.should_stop()`.
