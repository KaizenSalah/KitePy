## Optimizers (`optimizer`)

Configure `optimizer` with a string name, optimizer class/callable `(param_groups, **kwargs)`, or an instantiated `torch.optim.Optimizer`:

| Name | Optimizer | Default Extra Behavior |
|---|---|---|
| `"adamw"` (default) | `torch.optim.AdamW` | Automatic bias & norm `weight_decay=0.0` exclusion |
| `"adam"` | `torch.optim.Adam` | Same parameter grouping |
| `"sgd"` | `torch.optim.SGD` | Sets `momentum=0.9` unless passed in `optimizer_kwargs` |
| `"rmsprop"` | `torch.optim.RMSprop` | — |
| `"adadelta"` | `torch.optim.Adadelta` | — |
| `"adagrad"` | `torch.optim.Adagrad` | — |
| `"adamax"` | `torch.optim.Adamax` | — |
| `"nadam"` | `torch.optim.NAdam` | — |
| `"radam"` | `torch.optim.RAdam` | — |
| `"lion"` | `lion_pytorch.Lion` | Requires `pip install lion-pytorch` |

Pass optimizer-specific arguments cleanly via `optimizer_kwargs`:

```python
model.train("cifar10", optimizer="sgd", lr=0.05, optimizer_kwargs={"momentum": 0.9, "nesterov": True})
```

## Parameter Groups, Differential LR, & Layer Decay

`build_parameter_groups()` automatically excludes `weight_decay` for `1D` tensors and parameters whose names contain `bias`, `norm`, `bn`, `ln`, `layernorm`, or `rmsnorm`.

- **Dict LR**: `lr={"backbone": 1e-4, "head": 1e-3}` sets separate learning rates for head vs. backbone parameters (`get_head_parameter_names()`).
- **`backbone_lr_mult`**: When `lr` is scalar (e.g., `lr=1e-3, backbone_lr_mult=0.1`), backbone parameters use `1e-4` while the head keeps `1e-3`.
- **`layer_decay`**: Applies exponential depth-based decay (`backbone_lr * layer_decay ** depth_from_top`) across numbered Transformer/ResNet layers.

## Learning Rate Schedulers (`scheduler`)

| Name | Schedule Mode | Notes |
|---|---|---|
| `"cosine"` (default) | per-step | `CosineAnnealingLR` over `main_steps` |
| `"warmup_cosine"` / `"cosine_warmup"` | per-step | Same cosine main schedule (combine with `warmup_steps`) |
| `"linear"` | per-step | Linear decay (`start_factor=1.0 -> 0.0`) |
| `"polynomial"` | per-step | `PolynomialLR` (pass `power` via `scheduler_kwargs`) |
| `"onecycle"` | per-step | `OneCycleLR` honoring per-group LRs as `max_lr` |
| `"step"` | per-epoch | `StepLR` (`step_size` defaults to `max(1, epochs // 3)`, `gamma=0.1`) |
| `"multistep"` | per-epoch | `MultiStepLR` |
| `"exponential"` | per-epoch | `ExponentialLR` (`gamma=0.95` default) |
| `"plateau"` | per-epoch | `ReduceLROnPlateau` monitoring `val_loss` (or `train_loss`) |
| `"constant"` / `"none"` | none / warmup only | Optional linear warmup without decay |

### Warmup Steps (`warmup_steps`)

- `int` (e.g., `warmup_steps=500`): exact number of warmup optimizer steps.
- `float` in `(0, 1)` (e.g., `warmup_steps=0.1`): fraction of total optimizer steps.

Composes `LinearLR(start_factor=0.1, end_factor=1.0)` with the main step scheduler via `SequentialLR`.

## Exponential Moving Average (`ema`)

Enable EMA shadow weights for smoother evaluation and higher final accuracy:

```python
model.train("cifar10", epochs=20, ema=True, ema_decay=0.9999)
```

During training, validation uses `self.ema.shadow` (`ModelEMA`). At the end of `Engine.train()`, EMA shadow weights are copied onto `self.model` for inference and `.save()`.

## Automatic LR Finding (`lr="auto"` / `lr_find=True`)

```python
# Automatic before training starts
CNN("resnet18").train("cifar10", epochs=10, lr="auto")

# Or standalone inspection
lr = model.find_lr("cifar10")
model.train("cifar10", lr=lr)
```
