## Overview

`BaseModel.train()` orchestrates config merging, data loading, model construction, and `Engine` execution, returning `self` for clean method chaining.

<CodeGroup>
```python Minimal
from kitepy import CNN

CNN("resnet18").train("cifar10")
```

```python Full Training Controls
from kitepy import CNN

model = CNN("resnet50", pretrained=True)
model.train(
    data="./my_dataset",
    epochs=30,
    batch_size=64,
    gradient_accumulation_steps=2,
    lr=3e-4,
    loss="cross_entropy",
    class_weights="balanced",
    label_smoothing=0.05,
    val_every_n_epochs=1,
    val_check_interval=1.0,
    save_every_n_epochs=1,
    save_top_k=3,
    checkpoint_dir="./checkpoints",
    early_stopping=True,
    early_stopping_patience=5,
)
```
</CodeGroup>

## Duration & Batching

- **Epoch-based**: `epochs=50` (default `10`).
- **Step-based**: `max_steps=5000` stops cleanly once `global_step >= max_steps` (and auto-computes needed epochs if `max_epochs <= start_epoch`).
- **Auto batch size**: `batch_size="auto"` selects batch size via `auto_batch_size("base", free_gb)` on CUDA or `32` on CPU.
- **Gradient accumulation**: `gradient_accumulation_steps=4` scales loss by `1 / accum_steps` (handles remainder batches safely at epoch end and `max_steps`).

---

## Validation & Debugging Controls

- **`val_every_n_epochs`**: Run validation every `N` epochs (always validates on the final epoch `epoch == max_epochs`).
- **`val_check_interval`**: Float in `(0, 1.0)` triggers mid-epoch validation at fractional milestones; integer `> 0` runs validation every `N` training batches.
- **`fast_dev_run=True`**: Forces `epochs=1` and stops training/validation loops after 1 batch for instant smoke testing.
- **`overfit_batches`**: `int` caches `N` batches; `float` in `(0, 1.0)` caches that fraction of batches so you can verify memorization on a small subset.
- **`detect_anomaly=True`**: Wraps forward/backward passes in `torch.autograd.detect_anomaly()`.

## Loss Functions (`loss`)

`create_loss_function()` accepts an `nn.Module`, a custom callable, or any of these built-in string names:

| Config Name | PyTorch / KitePy Module | Notes |
|---|---|---|
| `"cross_entropy"` / `"ce"` | `nn.CrossEntropyLoss` | Supports `class_weights` and `label_smoothing` |
| `"focal"` | `FocalLoss(gamma=2.0)` | Built-in focal loss supporting `class_weights` |
| `"bce"` / `"binary_cross_entropy"` | `nn.BCEWithLogitsLoss` | Maps `class_weights` to `pos_weight` |
| `"mse"` / `"l2"` | `nn.MSELoss` | Regression default |
| `"mae"` / `"l1"` | `nn.L1Loss` | L1 regression |
| `"smooth_l1"` | `nn.SmoothL1Loss` | Huber-like smooth L1 |
| `"huber"` | `nn.HuberLoss` | Robust regression |
| `"kl_div"` / `"kld"` | `nn.KLDivLoss(reduction="batchmean")` | KL divergence |
| `"nll"` | `nn.NLLLoss` | Negative log-likelihood (supports `class_weights`) |
| `"margin"` | `nn.MultiMarginLoss` | Multi-class hinge margin loss |

### Automatic Class Balancing

Pass `class_weights="balanced"` on imbalanced datasets to automatically compute inverse-frequency weights from dataset targets (`Tensor` or folder `ImageFolder` targets, including `Subset` splits):

```python
CNN("convnext_tiny", pretrained=True).train(
    "./imbalanced_folders",
    epochs=10,
    class_weights="balanced",
)
```

## Resuming Training

Pass `resume_from_checkpoint="checkpoints/model_epoch5_loss0.3412.pt"` to restore model weights, optimizer, scheduler, `GradScaler`, `ModelEMA`, `global_step`, `best_val_loss`, and `history`.

<Note>
Resume loading defaults to strict `weights_only=True`. If resuming model weights from a checkpoint whose optimizer parameter groups differ (such as a `ModelCheckpoint` callback file or changed optimizer config), KitePy logs a warning and resumes model weights cleanly with fresh optimizer state.
</Note>
