## Quick Usage (String Shortcuts or Instances)

Pass string shortcuts or instantiated callback objects to `.train(..., callbacks=[...])`:

```python
from kitepy import CNN, EarlyStopping, ModelCheckpoint, CSVLogger

model = CNN("resnet18")
model.train(
    "cifar10",
    epochs=20,
    callbacks=[
        "lr_monitor",
        EarlyStopping(monitor="val_loss", patience=3),
        ModelCheckpoint(filepath="ckpts/ep_{epoch:02d}_{val_loss:.4f}.pt", save_top_k=2),
        CSVLogger(log_dir="./logs", filename="metrics.csv"),
    ],
)
```

### Supported String Shortcuts (`CallbackList`)

- `"early_stopping"` → `EarlyStopping()`
- `"lr_monitor"` → `LRMonitor()`
- `"progress"` → `ProgressLogger()`
- `"csv"` → `CSVLogger()`
- `"tensorboard"` → `TensorBoardLogger()`
- `"wandb"` → `WandbLogger()`
- `"checkpoint"` → `ModelCheckpoint()`

You can also enable built-in loggers directly on `TrainingConfig`:
- `csv_log_dir="./logs"` auto-attaches `CSVLogger(log_dir="./logs")`
- `tensorboard_dir="./runs"` auto-attaches `TensorBoardLogger(log_dir="./runs")`
- `wandb_project="my_project"` auto-attaches `WandbLogger(project="my_project")`

## Built-In Callback Behavior

### `ModelCheckpoint`

```python
ModelCheckpoint(
    filepath: str = "checkpoints/model_{epoch:02d}.pt",
    monitor: str = "val_loss",
    save_best_only: bool = False,
    save_top_k: int = 3,
    mode: str = "min",
)
```

- Supports `{epoch}`, `{val_loss}`, and `{train_loss}` template placeholders (falls back to `train_loss` if the monitored metric is `None`).
- **Metric-ranked `save_top_k`**: tracks scores per saved path so constant filepaths (e.g. `"best.pt"`) never self-delete, and `save_best_only=False` + `save_top_k=k` always retains the `k` best-scoring checkpoints rather than evicting chronologically.
- Saves `epoch`, `global_step`, `best_val_loss`, `model_state_dict`, `optimizer_state_dict`, `metrics`, and `history`.

### `CSVLogger`

```python
CSVLogger(log_dir: str = "logs", filename: str = "metrics.csv")
```

Automatically expands header columns and rewrites earlier rows with empty cells (`restval=""`) if new metrics appear on later epochs (for example, `val_loss` / `val_acc` appearing on Epoch 2 when `val_every_n_epochs=2`).

### `EarlyStopping`

```python
EarlyStopping(monitor: str = "val_loss", patience: int = 5, min_delta: float = 1e-4, mode: str = "min")
```

Sets `should_stop = True` once `counter >= patience` epochs pass without improving beyond `min_delta`.

### `LambdaCallback`

Create lightweight inline hooks without subclassing `Callback`:

```python
from kitepy import LambdaCallback

cb = LambdaCallback(
    on_epoch_end=lambda trainer, epoch, metrics, **kw: print(f"Finished epoch {epoch}: {metrics}")
)
```

Available hooks across all `Callback` subclasses: `on_train_start`, `on_train_end`, `on_epoch_start`, `on_epoch_end`, `on_batch_start`, `on_batch_end`, `on_validation_start`, `on_validation_end`.
